## 今日媒体行业透镜（跨源汇总）

### 共识

1. **AI 开始优化运行自己的基础设施**：36氪/新智元 7/30 集中报道 GPT-5.6 Sol 通过 Codex 重写生产 GPU 内核，服务成本降 20%、token 效率升 15%+。媒体共识：竞争轴从「谁 GPU 多」转向「同样硬件谁能榨出更多 token」；推理效率与芯片数量同等重要。
2. **企业级 AI Coding 市场进入百亿美元量级**：36氪 7/30《大厂暗战百亿市场》援引 Gartner，年化规模 98–110 亿美元；Coding Agent 是企业持续运行 Agent 的首个核心场景，也是 Token 消耗最重的应用类型之一。
3. **「自优化飞轮」而非「完整自进化」**：多家媒体区分 OpenAI「分析流量→写代码→实验→验证」闭环与「AI 在线改自己权重」的递归自我改进（RSI）；当前阶段更准确描述为基础设施自优化，部署仍经人工审核与 FpSan 等工具验证。
4. **移动 Agent 工作流延续昨日共识**：虎嗅 7/29 文章（7/30 仍在传播）将 Cursor/Codex 手机端定义为审批控制台；7/30 无 Cursor 新 Changelog，共识从「新功能」转为「能力常态化」。

### 分歧

1. **「AI 自进化」叙事是否过度**：36氪 7/30 明确写「还不算 AI 开始自我进化」，权重未在线改动；OpenAI 官方与 Brockman 强调降本数字与飞轮。部分传播稿使用「AI 给自己写代码」标题，与审慎技术解读存在温差。
2. **是否阅读 AI 生成代码（延续性争论）**：InfoQ 7/30 发布《编程界新分水岭：Uncle Bob 说绝不读 AI 写的代码，Hashimoto 却说他逐行阅读》，重提 7/3 虎嗅与 Hashimoto 推文对立。Uncle Bob 主张变异测试、Gherkin、QA 围墙；Hashimoto 坚持逐行阅读建立直觉。媒体未给出胜负，代表两种治理哲学。
3. **Kimi K3「开源」边界**：36氪 7/30《Kimi K3公开了不少秘密，但最重要的 Infra 却很难抄》认为权重开放不等于 Infra 可复制；与 7/27–28「全面开源」热情稿形成张力，聚焦 MoonEP/FlashKDA 工程门槛而非模型分数。
